KopiKita Cafe — Project Praktikum PAW Modul 2

Cara menjalankan:
1. Ekstrak folder coffee_cafe_paw ke C:\laragon\www\coffee_cafe_paw.
2. Jalankan Laragon dengan Start All.
3. Buka http://localhost/phpmyadmin lalu import file database.sql.
4. Pastikan database paw_modul2_coffee_cafe berhasil dibuat.
5. Buka http://localhost/coffee_cafe_paw/index.php.

Fitur: katalog, pencarian, tambah data, detail, edit, dan hapus menu.
Teknologi: PHP, MySQL, HTML, CSS.
